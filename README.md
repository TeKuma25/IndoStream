# IndoStream CloudStream Repository 🇮🇩

Repositori resmi penyedia ekstensi dan provider CloudStream berbahasa Indonesia.

## 📱 Cara Menggunakan di CloudStream

1. Buka aplikasi **CloudStream** di HP atau Android TV Anda.
2. Buka menu **Pengaturan** (Settings) > **Ekstensi** (Extensions).
3. Klik tombol **Tambah Repositori** (Add Repository).
4. Masukkan URL repositori IndoStream berikut:
   ```
   https://raw.githubusercontent.com/TeKuma25/IndoStream/builds/repo.json
   ```
5. Klik **Tambahkan**.
6. Pilih provider yang ingin Anda pasang, lalu klik **Instal**.
